# Temperature Conversion System (React GUI)

## Project Title
Temperature Conversion System

## Description
This project is a GUI-based Temperature Conversion System built with React.  
It allows users to convert temperature values between Celsius (C), Fahrenheit (F), and Kelvin (K).

The application validates user input, handles invalid values gracefully, and prevents conversions below absolute zero.  
It was developed as Task 01 for the **Orphion Tech Internship Program**.

---

## Features
- Convert temperatures between Celsius, Fahrenheit, and Kelvin
- Input validation for non-numeric values
- Absolute zero validation for all units
- Swap units functionality
- Reset/Clear inputs
- Clean, responsive user interface built with React

---

## Technologies Used
- React (JavaScript)
- HTML5
- CSS3
- Vite (development environment)

## How to Run the Project

2. Navigate into the project directory:
